# Security

Skryba records audio, holds an API key and uses the Accessibility permission, so security reports
are taken seriously.

**Please report vulnerabilities privately**, not in a public issue: use
[Report a vulnerability](https://github.com/heartmade-studio/heartmade-skryba/security/advisories/new)
on GitHub. Include the steps to reproduce and the macOS version. You'll get a reply within a week.

Only the latest version on `main` is supported.
